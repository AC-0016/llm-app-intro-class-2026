# LLMアプリの学習ノート

## APIキーの保管
毎回の授業開始時に、起動するターミナルでAPIキーをサーバー側の環境変数OPENAI_API_KEYに設定します。キーは非表示で入力し、ファイルやCodespaces Secretsに保存しません。授業終了時はサーバーを停止して環境変数を解除し、ターミナルを閉じます。HTML、JavaScript、スクリーンショット、GitHubへのコミットにキーを含めません。

## 検索と生成の役割
検索は質問に関係する資料を選びます。生成は選んだ資料を使って文章を作ります。検索の失敗と、資料を渡した後の回答の失敗を分けて調べます。資料IDが付いていても内容が正しいとは限りません。

## 根拠が足りない質問
登録資料に答えがない場合、アプリは資料から確認できないと伝える設計にします。推測した試験日や提出期限を事実のように回答しません。
