## ベクトルとは

数値を並べたものです。説明用の例：

```python
a = [1.0, 0.0, 1.0]
b = [0.9, 0.1, 1.0]
c = [0.0, 1.0, 0.0]
```

実際のEmbeddingは、多数の次元を持ちます。
各数値を「価格」「色」のように直接解釈できるとは限りません。

---

## 説明用ベクトルの向き

実際のEmbeddingではなく、計算用の2次元の例です。

| ベクトル | 成分 | aとの関係 |
|---|---|---|
| a | [1, 0] | 基準 |
| b | [2, 0] | 長さは違うが同じ向き |
| c | [0, 1] | 直交する向き |
| d | [-1, 0] | 反対向き |

コサイン類似度では、長さよりも向きの関係を比べます。

## 2つのタイミング

| 資料の登録・更新時 | 質問を受けたとき |

| 次の質問で再利用 | 上位の本文を取得して生成へ |

## 登録時に残るもの

1. `all_chunks()` で資料の断片を取得する
2. 資料名・見出し・本文をつなぎ、`embed()` に渡す
3. ベクトルをJSON文字列にしてDBへ保存する
4. 使用したモデル名も同じ行へ保存する

原本の本文は、そのまま別のカラムに残ります。
質問のたびに、資料のEmbedding APIを呼び直す必要はありません。

---

## 質問時に行うこと

1. 保存済みベクトルと、現在のモード・モデル名を確認する
2. 質問を `embed()` に渡す
3. 質問と各資料のベクトルの類似度を計算する
4. 正のスコアの上位から本文を取得して、回答生成へ渡す

検索に使う数値と、生成に使う本文は役割が異なります。

## コサイン類似度

2つのベクトルの向きの近さを計算します。

内積を、それぞれの長さの積で割ります。

```text
内積 = a[0]×b[0] + a[1]×b[1] + …
長さ = 各成分の2乗の合計の平方根
類似度 = 内積 ÷ (aの長さ × bの長さ)
```

同じ向きは1。ゼロベクトルは教材では0として扱います。

---

## 同じ向きの計算例

a = [1, 0]、b = [2, 0] の場合：

| 計算 | 結果 |
|---|---|
| 内積 | 1×2 ＋ 0×0 = 2 |
| aの長さ | √(1² ＋ 0²) = 1 |
| bの長さ | √(2² ＋ 0²) = 2 |
| コサイン類似度 | 2 ÷ (1×2) = 1 |

長さが2倍でも、同じ向きなら類似度は1です。

---

## 向きが異なる計算例

a = [1, 0] を基準にします。

| 比較相手 | 内積 | 長さの積 | 類似度 |
|---|---|---|---|
| [0, 1] | 0 | 1 | 0 |
| [-1, 0] | -1 | 1 | -1 |

ゼロベクトルは長さが0なので、そのままでは割り算できません。
教材は、どちらかがゼロベクトルなら0を返します。

---

## forで内積を計算

```python
for i in range(len(a)):
    dot += a[i] * b[i]
    a_size += a[i] * a[i]
    b_size += b[i] * b[i]
```

`i` はリストの位置です。同じ位置の成分同士を掛けます。
教材では専用の数値計算ライブラリを使わず、処理を追えるようにします。

---

## ループの途中の値

a = [1, 2]、b = [2, 1] で計算します。

| 段階 | dot | a_size | b_size |
|---|---|---|---|
| 初期値 | 0 | 0 | 0 |
| i = 0 の後 | 2 | 1 | 4 |
| i = 1 の後 | 4 | 5 | 5 |

類似度は 4 ÷ (√5 × √5) = **0.8** です。
`a_size` と `b_size` は、この段階では長さの2乗です。

## スコアの読み方

類似度は、回答が正しい確率ではありません。
また、キーワード検索の点数と同じ尺度でもありません。

- 高いスコアでも、質問の答えが含まれない場合がある
- 固有名詞や記号はキーワード検索が役立つ場合もある
- 件数やしきい値は、評価用質問で検討する

この教材は正のスコアから上位件数を選ぶ単純な実装です。


## ベクトルの不一致を直す手順

| 状態 | 対応 |
|---|---|
| 原本の本文を変更した | init_db.py、その後build_index.py |
| デモからAPIに切り替えた | 新しい設定でbuild_index.py |
| Embeddingモデルを変更した | 新しいモデルでbuild_index.py |

APIモードでは資料のベクトル化にも外部通信が発生します。
エラーを隠すためにモデル名だけを書き換えず、ベクトルを再作成します。
